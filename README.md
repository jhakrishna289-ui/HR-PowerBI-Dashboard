# HR Analytics & Employee Attrition Dashboard

## 📊 Project Overview
This project features an interactive **HR Analytics Dashboard** that provides deep insights into employee data, focusing heavily on **Attrition Analysis**. The goal of this dashboard is to help HR departments understand the driving factors behind employee turnover and make data-driven decisions to enhance employee retention and workplace satisfaction.

## 📈 Key Metrics Tracked
* **Total Employees:** 1,470
* **Total Attrition:** 237 employees have left the organization.
* **Attrition Rate:** 16.12%

## 🔍 Key Insights & Visualizations Included
1. **Attrition Rate % by Distance From Home:** A line chart showcasing how commute distance affects the likelihood of an employee leaving.
2. **Avg Monthly Income by Job Role:** A bar chart comparing average salaries across various roles (e.g., Managers vs. Sales Representatives).
3. **Attrition Rate % by Job Role & Work-Life Balance:** A breakdown showing how job pressure and balance ratings directly impact attrition.
4. **Total Attrition by Department:** A donut chart showing the percentage distribution of attrition across fields like *Research & Development (56.12%)*, *Sales (38.82%)*, and *Human Resources (5.06%)*.
5. **Interactive Filters (Slicers):** Clean sidebar filters to drill down data by *Department, OverTime, Business Travel, and Gender*.
